# Στέλλα & Χρήστος · Χανιά

Στατικό site για τον γάμο: πρόγραμμα, διαδραστικός χάρτης με διαδρομές, οδηγός για τα Χανιά (παραλίες, αξιοθέατα, φαγητό) και RSVP που καταλήγει σε Google Form.

Δεν χρειάζεται build. Ανεβαίνει όπως είναι στο GitHub Pages.

## Αρχεία

| Αρχείο | Τι αλλάζετε εκεί |
| --- | --- |
| `assets/js/config.js` | Ημερομηνία, ναός, κέντρο, συντεταγμένες, ρυθμίσεις Google Form |
| `assets/js/places.js` | Οι προτάσεις για τα Χανιά (προσθήκη / αφαίρεση) |
| `index.html` | Κείμενα, FAQ, ερωτήσεις της φόρμας |
| `assets/css/style.css` | Χρώματα (στην αρχή του αρχείου, στο `:root`) |
| `google-apps-script/create-rsvp-form.gs` | Script που φτιάχνει αυτόματα το Google Form |

## 1. Στοιχεία γάμου

Ανοίξτε το `assets/js/config.js` και αλλάξτε ό,τι λέει **ΣΥΜΠΛΗΡΩΣΤΕ**: ημερομηνία, ώρες, ονόματα και διευθύνσεις ναού και κέντρου.

Για τις συντεταγμένες: στο Google Maps κάντε δεξί κλικ στο σημείο και πατήστε τους αριθμούς. Αντιγράφονται στο πρόχειρο (π.χ. `35.5145, 24.0185`). Ο πρώτος αριθμός μπαίνει στο `lat` και ο δεύτερος στο `lng`.

## 2. Σύνδεση με Google Form (RSVP)

### Αυτόματα (προτείνεται)

1. Πηγαίνετε στο https://script.google.com με τον λογαριασμό της Στέλλας και πατήστε **Νέο έργο**.
2. Επικολλήστε το περιεχόμενο του `google-apps-script/create-rsvp-form.gs`.
3. Στη γραμμή `STELLA_EMAIL` βάλτε το email της, αν θέλει να παίρνει email για κάθε απάντηση.
4. Επιλέξτε `createRsvpForm` και πατήστε **Run**. Θα ζητήσει να εγκρίνετε δικαιώματα.
5. Στο **Execution log** θα εμφανιστεί ένα μπλοκ `rsvp: { ... }`. Αντικαταστήστε με αυτό το αντίστοιχο μπλοκ στο `config.js`.

Το script φτιάχνει:
- το Google Form με όλες τις ερωτήσεις,
- ένα Google Sheet όπου μαζεύονται οι απαντήσεις,
- email στη Στέλλα για κάθε νέα απάντηση.

### Χειροκίνητα

1. Φτιάξτε Google Form με τις ίδιες ερωτήσεις. Οι επιλογές πρέπει να είναι **ακριβώς ίδιες** με του `index.html`, π.χ. `Ναι, με χαρά!`.
2. Από το μενού ⋮ επιλέξτε **Λήψη προσυμπληρωμένου συνδέσμου**, συμπληρώστε τα πάντα και πατήστε **Λήψη συνδέσμου**.
3. Στον σύνδεσμο θα δείτε `entry.123456=...` για κάθε ερώτηση. Βάλτε αυτά τα IDs στο `config.js`.
4. Για το `formAction`, πάρτε το URL της φόρμας και αλλάξτε το `/viewform` σε `/formResponse`.
5. Για ειδοποιήσεις μέσω email: στην καρτέλα **Απαντήσεις**, ⋮ → **Λήψη ειδοποιήσεων μέσω email για νέες απαντήσεις**.

> Η φόρμα πρέπει να δέχεται απαντήσεις από **οποιονδήποτε έχει τον σύνδεσμο**, χωρίς υποχρεωτική σύνδεση. Ελέγξτε ότι είναι Published.

Όσο το `formAction` περιέχει `ΒΑΛΤΕ_ΤΟ_ID`, η φόρμα δουλεύει σε **δοκιμαστική λειτουργία**: δεν στέλνει τίποτα και γράφει στο console τι θα έστελνε.

**Δοκιμή:** στείλτε μια απάντηση από το site και ελέγξτε ότι εμφανίστηκε στο Google Sheet.

## 3. Δημοσίευση στο GitHub Pages

Settings → Pages → Source: **Deploy from a branch**, branch `main`, φάκελος `/ (root)`. Το site θα είναι στο `https://<username>.github.io`.

## Τοπική προεπισκόπηση

```bash
python3 -m http.server 8000
```

Ανοίξτε το http://localhost:8000

## Τεχνικά

- Χάρτες: [Leaflet](https://leafletjs.com) με tiles από OpenStreetMap.
- Διαδρομές: δημόσιο demo του [OSRM](https://project-osrm.org). Αν δεν απαντήσει, ο χάρτης δείχνει ευθεία γραμμή και κουμπί για Google Maps.
- RSVP: `POST` σε `no-cors` στο `formResponse` του Google Form. Γι' αυτό η σελίδα δεν μπορεί να ξέρει αν η αποστολή πέτυχε. Η δοκιμή γίνεται ελέγχοντας το Sheet.
- Intro με φάκελο: εμφανίζεται μία φορά ανά επίσκεψη και όχι σε όσους έχουν ενεργοποιημένο το «μειωμένη κίνηση». Για να το ξαναδείτε, ανοίξτε τη σελίδα με `?intro` στο τέλος του URL.
- Αν αλλάξετε CSS/JS, ανεβάστε τον αριθμό `?v=` στο `index.html`, ώστε οι επισκέπτες να μη βλέπουν παλιά αρχεία από την cache.
